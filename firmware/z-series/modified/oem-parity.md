# Pico Z features and their equivalents

This comparison covers the recovered Z-series 0.0.119 application and the standalone 1.0.0 application. The firmware identifies itself as Pico Z. The archive does not establish which hardware revisions of Z1, Z2 or multi-module machines can use a given image.

## What a Z recipe specifies

Program Maker writes temperatures in Celsius and hold and drain durations in **seconds**. The editor can display Fahrenheit and minutes. Program and step names support up to 20 printable ASCII characters. The beer setting changes setup prompts. PicoPak mode changes the physical valve mapping for adjuncts. It does not identify a kit or set its strength. The standalone compiler explicitly stops heating for an unheated step. Stock can retain the previous setpoint across a step or operator pause. A positive drain stops the PID. The Hub checks that distinction when exporting for stock. ## Archived kits and strength adjustments

The stock brewer also had a separate cloud recipe path. Its non-PicoPak format uses location 0–5 for six flow paths and 6 for a pause. Its PicoPak path uses 1–6 for flow and an action field for pauses. Source water, setup flags, temperature adjustments at local boiling point and water prompts can differ from local Program Maker programs. An original kit's strength and bitterness settings adjust mash and adjunct **time** within that kit's authored ranges. These settings require valid original targets and minimum and maximum step times. An ingredient list, style name or a local Program Maker file cannot establish those ranges. [Original reader](../reverse-engineered/adapters/arduinojson/program_recipe_json.cpp), [original compiler and dose adjustments](../reverse-engineered/src/program_recipe.cpp)

The Hub retains archived source schedules and provenance. For example, its archive includes 39 source-model Z programs. The 27 kit records include a starting-water quantity and type code. The other 12 are community records. Archive presence establishes a preserved schedule, not a complete ingredient recipe or verified conversion. A user can send an ingredient recipe with a validated Z adaptation or a local Program Maker recipe. The Hub can send all 39 byte-verified source Z schedules to standalone Z firmware advertising `z_cloud_program_v1`. The original Z compiler receives the starting water, target temperatures, times, pause markers and device-measured boiling point. Its zero target retains the previous heating state, and its chiller steps require operator preparation. The 39 schedules have no machine-authored ingredient quantities. A different capability, `z_picopak_v1`, runs the original PicoPak compiler for operators with a surviving pack and the Z PicoPak Adapter. It displays the native adapter prompt and uses the 6.81 L process charge. Original authored dose ranges govern optional ABV/IBU changes. The 3,836 preserved original programs include 3,694 with device-compatible labels. The others require an explicitly reviewed device label. These schedules belong in the archive. Vendor kit redemption and cloud account lookups remain unavailable. ## Verification boundary

The controller tests exercise saved-program compilation, native status, command dispatch, interlocks, persistent history and recovery. Browser tests exercise Program Maker import, editing and capture. These checks do not establish physical valve alignment, kettle temperatures, network availability on a particular board, successful installation or a completed brew.
