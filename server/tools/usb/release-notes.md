The Hub and custom firmware for Pico S, Pico Pro, both Pico C display variants, individual Z-series modules, Zymatic, PicoFerm and PicoStill are **1.0.0**. Update the Hub to get new browser and journal features without reflashing a machine that already runs the matching firmware.

Use the Hub to build recipes, control compatible machines, review brew history, and see model-specific cleaning reminders. A paired PicoFerm records while its Wi-Fi radio sleeps. A short press wakes it for management. To connect a standalone PicoFerm to a batch, open the batch in **Brew journal**, choose **Ferment**, and select its monitor. To convert a stock machine, connect it to the computer running the Hub and open **Brewery → Add machine → USB setup and recovery**. Keep a private copy of the Hub data directory after it saves the original firmware.

On the Brewery page, select **Group machines** to link individual brewers for a larger batch or a side-by-side comparison. Each invited brewer accepts separately. A compatible Z can use its dial, local website or the Hub. Grouped Z modules can also share coffee settings and invite each other to sous vide, PicoStill and utility programs. A Z can also pair with a standalone PicoStill and use either Wi-Fi or wired Ethernet. Its recipe library supports original Program Maker files, archived Z recipes with their setup water, and original PicoPak schedules for use with the physical adapter. [Z features and compatibility](https://github.com/jeffreydwalter/picobrew/blob/v1.0.0/firmware/z-series/modified/oem-parity.md)

The brew assistant supports Google Gemini with a Google AI Studio API key. Open **Settings → AI** to choose the provider and a model available to your key. You can draft a recipe, ask about a live brew, or review a recorded session.

If your brewer runs development firmware with a higher version number, update the Hub first. Select **Check for Updates** on the machine’s Firmware page. Wireless installation requires the matching recovery layout. For an earlier dual-bank PicoFerm running 1.0.0, connect it by USB and choose **Install standalone firmware** in the Hub that holds its original backup and device key. The installer verifies the existing banks and preserves the device’s history and pairing. Earlier layouts without recovery and both Zymatic profiles also use USB. A Zymatic can fetch recipes and report sessions to the Hub over Wi-Fi. Its local website and API work over Wi-Fi at Home and for readings at programmed pauses. Use Ethernet for continuous access during heating, circulation and draining. Zymatic firmware is prepared with the individual brewer’s identity. Physical qualification varies by model. [Setup and compatibility](https://github.com/jeffreydwalter/picobrew#3-connect-your-machine)

Download the **picobrew-hub** executable for your computer. Run it with `--version` to check the release. It includes the Hub website, USB programmer and firmware resources. The separate `picobrew-usb` executables are build inputs for users building the Hub from source. `SHA256SUMS.txt` covers all downloads. `releases.json` identifies the exact source commit and the size and SHA-256 of every Hub and worker.

Use Linux ARM64 for a 64-bit Raspberry Pi OS installation and Linux ARM for 32-bit Raspberry Pi OS on ARMv7 or newer. Linux binaries use glibc. USB access requires the Hub account to have access to the physical port or USB adapter. Follow the device and power prompts in the Hub. Backup and setup preserve the existing model and flash-layout checks. Firmware changes for a named Z stack require independently qualifying its individual module.

Build sources and the checked-in firmware manifests are available at this release tag. The USB worker includes the project’s MCU-specific tools, the CPython runtime and third-party libraries. The accompanying source archive contains the programmer sources. Each platform has a ZIP with the license for original project contributions, the Hub license and the runtime and dependency notices from its build. OEM images, artwork, recipes and manuals retain their existing notices.
